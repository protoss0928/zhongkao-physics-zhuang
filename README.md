## 一、是什么

一个**电脑/PAD/手机/微信内都能直接打开**的 HTML 单页应用，**不需要服务器、不需要联网**（首次加载后离线可用）。

**核心特点**：
1. **83 道题**（22 章全覆盖）— 少而精，符合中考高频考点
2. **题型多样** — 47 选择 + 36 填空，比例约 6:4
3. **艾宾浩斯智能复习** — 答错重返快，答对周期拉长
4. **多用户** — 兄弟/同学各自独立进度
5. **多科目模板** — `data/` 目录放不同科目的 JSON 即可换科目
6. **本地存储** — IndexedDB（电脑/微信均可），可导出 JSON 备份
7. **音效** — 答对/答错/连击/升级 4 种 Web Audio API 现生成，可关闭

## 三、3 种打开方式

### 方式 1：电脑直接双击 `index.html`（最简单）
- 双击文件，浏览器打开
- ⚠️ 部分浏览器对 `file://` 协议下的 `fetch` 有限制，推荐方式 2

### 方式 2：本地起 HTTP server（推荐）
```bash
cd 中考物理核心考点复习
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

### 方式 3：部署到服务器 / 微信内置浏览器
1. 把整个文件夹传到任意静态服务器（Nginx/Vercel/Netlify/腾讯云 COS）
2. 把链接发给微信好友，**微信内置浏览器可以直接打开**
3. ⚠️ 微信内**第一次**打开会自动提示"已复制链接"，说明已经成功打开

## 五、Ebbinghaus 复习算法

**默认间隔**（单位：天）：

| 当前等级 | 答对后升级 | 答错后重置 |
|---|---|---|
| 0 | 1 天 → 1 | 0 |
| 1 | 3 天 → 2 | 0 |
| 2 | 7 天 → 3 | 0 |
| 3 | 15 天 → 4 | 0 |
| 4 | 30 天 → 5 | 0 |
| 5 | 30 天（封顶）| 0 |

**距中考 ≤ 7 天**：所有间隔自动压缩到 ≤ 2 天  
**距中考 ≤ 3 天**：所有间隔压缩到 ≤ 1 天  
（**专门为 17 天倒计时设计**——临考期复习会变频繁）

## 六、扩展到其他科目（化学/数学/英语/语文）

**只需要做 3 步**：

1. 复制 `data/physics/` → `data/chemistry/`（或任意科目名）
2. 改 `chapters.json` 的 `subject` / `subject_name` / `chapters` 数组
3. 改 `questions.json` 的 `questions` 数组

**核心代码 0 修改**！所有模块都是题型无关的。

**如果想给"化学"用别的颜色**：改 `chapters.json` 里 `chapters[].color` 字段。

**如果要替换入口的科目名/图标**：改 `index.html` 顶部 `<h1>` 和头部图标。

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 微信内打不开 | 确保用 HTTP server 启（file:// 不行）|
| 音效没声音 | 第一次需要点击页面任意位置（浏览器策略）|
| 答题记录丢了 | 检查是否换了浏览器/清空了缓存；用 💾 备份恢复 |
| 想要更多题 | 直接编辑 `data/physics/questions.json`，核心代码不动 |
| 想要不同颜色 | 改 `chapters.json` 里 `chapters[].color` 字段 |

## 十、技术栈

- **纯 HTML5 + 原生 JavaScript**（无任何依赖、无 npm）
- **IndexedDB** 本地存储（带 localStorage 降级以兼容微信）

- **CSS3** 响应式布局（手机/电脑/PAD 通用）
- 总代码 ~30KB（不含题库），加载速度 < 1 秒
